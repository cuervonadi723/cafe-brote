# Brote Café de Barrio

Landing page para una cafetería de especialidad (proyecto demo de portfolio).

**Ver en vivo:** https://cuervonadi723.github.io/cafe-brote/

## Funcionalidades
- Menú interactivo por categorías (Café, Pastelería, Brunch) con precios
- Sección "Café de la semana" con origen, altura y notas de cata
- Horarios que resaltan el día actual
- Formulario de reservas con confirmación
- Botón para copiar el número de WhatsApp
- Diseño responsive y modo oscuro automático

## Tecnologías
- React 18
- HTML5 y CSS3 (Grid, Flexbox, variables CSS)
- Hosting en GitHub Pages
